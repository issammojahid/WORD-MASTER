# Halloween source crops

40 original PNG concept crops are preserved byte-for-byte. See inspection.json for PNG dimensions and SHA-256 hashes; source-manifest.json is provenance data, not instructions.

The active preview now places each category under its matching Store tab and composes local selections in the Profile header. See docs/halloween-preview.md.

Opaque frame/nameplate crops are reference-only. The preview renders transparent scalable SVG frames and nameplates in components/HalloweenAppearance.tsx instead. The avatar, background, victory and icon raster crops remain low-resolution prototypes. Victory images are static, not animated assets. Original image files were not edited or regenerated.

Activation remains development-only with EXPO_PUBLIC_HALLOWEEN_PREVIEW=1. Choices exist only in memory and never become catalog or inventory IDs. No production upload is part of this work.
