# Royal client interface, 2027

The approved Moroccan night, gold and turquoise direction now uses real courtyard and hero artwork, transparent character cutouts, a sixteen-icon atlas, patterned beveled panels and native Arabic title plaques. Main menu, Store, Settings, Profile, Tasks and Achievements share these components. Gameplay keeps a compact header and top controls. Existing item identities, purchase confirmations and authoritative wallet rules remain unchanged.

Store keeps five columns at normal text sizes, a separate selection tray, and an explicit preview-only upcoming collection. Settings includes working text-size preferences, reduced motion and graphic quality controls. Profile statistics and earned badges use existing data rather than fabricated rewards. Four-card seasonal gift animation requires revealing all cards and selecting one; it grants nothing in this preview.

Leaderboard, rewarded-ad proposals, loss-refund proposals, unsupported power cards and weekly milestone rewards are visibly inactive previews. They require a later authorized backend phase. Final legal policy pages and native-device verification remain pending. Seasonal imagery is static concept artwork with UI-level animations, not fully animated production cosmetics.

No server, Supabase schema/data, deployment, push or Android release was performed in this phase. Local preview uses an isolated in-memory fixture. Type checking, focused regression tests and browser layout checks cover the client changes; browser checks do not replace an Android keyboard/voice/device test.
